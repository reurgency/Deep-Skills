The conductor · free add-on

deep-goal

/deep-goal <your feature> --rigor=mvp

The whole Deep-* series from one invocation - plan → review → implement → code-review → bugfix → docs - run hands-free at a rigor level you choose. deep-goal doesn't do the work; it conducts the six skills that do.

What it does for you

One command, the whole pipeline - on your terms

The six skills already chain together. deep-goal is the thin layer on top that walks the chain for you: it sequences the stages, hands each one a clean briefing, and checks the work before moving on.

▶

One invocation, end to end

Kick off the entire relay with a single command - or plain English: “take the export feature through the whole pipeline at mvp rigor.” Interactive stages run inline; the rest run hands-free.

◉

One dial: rigor

A single --rigor level - yolo, poc, mvp, or prod - sets which stages run, how interactive planning is, what review accepts automatically, and how many review→fix rounds the loop may take. One knob, from quick spike to production bar.

✓

Verifies artifacts, not claims

The conductor advances only when a stage's real artifact exists and that skill flipped its own status line - never on a sub-agent's say-so. A stage that didn't actually produce its output doesn't get to pass.

↻

Kill it, resume it

Pipeline state lives in a file, not the conversation. Close the session mid-run and re-invoke later - it resumes at the first unfinished stage, honoring your gates, budget, and worktree exactly as set.

The rigor dial

Four levels, from spike to production

Rigor is config-as-data: the shipped levels below are a starting point, and a repo can reshape or add its own without touching the skill. Omit the level and deep-goal asks once, recommending mvp.

Rigor Planning Runs Best for
yolo autonomous plan → implement throwaway spikes, fastest path to running code
poc autonomous plan → implement → code-review → bugfix proofs of concept that still get a review pass
mvp interactive plan → plan-review → implement → code-review → bugfix → docs real features - the recommended default
prod interactive full series + deeper review and more re-review rounds production work that has to hold up

Exact stage lists, review thresholds, and round caps per level live in the skill's rigor map - the table above is the shipped shape, summarized.

Hands-free, not hands-off

You keep the controls that matter

Autonomous doesn't mean opaque. Every human decision happens in the planning window up front; after that, three optional controls let you keep a hand on the wheel.

--gate=<stage>

Pause where you want

Inject a checkpoint before any stage - “pause before implement” - even in an otherwise hands-free run. It survives resume.

--budget=<band>

Cap the spend

A soft token ceiling checked at stage boundaries. Cross it and the run pauses and notifies; re-invoke to continue.

--worktree

Build in isolation

Run every post-planning stage in one dedicated git worktree; the final report ends with the merge instructions.

💬

Want to look before you leap? Add --dry-run (or ask “preview an mvp run”) and deep-goal prints the resolved pipeline and cost bands for your chosen rigor - dispatching nothing. It even works before Deep Skills is installed.

Where it fits

It sits above the six - it doesn't replace them

Every skill still does exactly one job, still writes the same artifacts, still runs perfectly well on its own. deep-goal just walks the same loop end-to-end. Coupling is one-directional: deep-goal knows the six; the six never require deep-goal.

plan→ plan-review→ implement→ code-review→ bugfix→ docs

An honest caveat

Best on Claude Code

deep-goal is designed and verified on Claude Code, where each autonomous stage runs as a fresh background agent with its own clean context - the isolation the fresh-eyes guarantee depends on.

⚠

On Codex, Cursor, and Copilot it runs the same stages in the same order, but inline and sequentially - one shared context window instead of a fresh agent per stage. Quick runs (yolo/poc) are comfortable; large prod-rigor runs can hit context limits and lose some reviewer independence. It's functional and honestly caveated, not yet gate-verified. If the pipeline matters, run it on Claude Code - and on any host you can end a session at a stage boundary and resume fresh.

Getting it

Free, and bundled with Deep Skills

deep-goal ships free in the same marketplace. It requires the Deep Skills plugin (v0.2.0 or newer) installed alongside - it verifies this at launch and declines politely if it's missing.

/plugin marketplace add reurgency/marketplace
/plugin install deep-skills@reurgency
/plugin install deep-goal@reurgency

Already have Deep Skills? Just the last line adds the conductor. Other hosts: see the install page.

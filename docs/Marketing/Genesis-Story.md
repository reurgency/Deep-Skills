# Other pages

There might be some room for some genesis subtleties on "How it works" page - subtle tho.    

We should emphasize that it works good for teams on all of the pages (where it makes sense and not forced). The commitable artifacts handoff is one benefit but the big one is teams benefit from basing processes and conversatations on a consistent context of deep-skills system so they don't end up with conversations like: What was your initial planning prompt? Did you have it write the plan so a fresh agent could handle it? How long did it take you to review the plan? What is your implementation routine? How do you go about code review? Did you remember to document? These questions and many more are smoothed out when the team operates from a reliable consistent platform.
 
Another phrase that can be laced thru all the pages is different varieties of, "If you ever tried X and saw the model do Y, you understand the value of _______ feature." These "experience" phrases are relateable and build credibility. I'm sure there are many opportunities to add these phrases in the skill pages, but here are the ones that I see:
- Last Mile
- No more "fixed" bugs that come right back
- Babysitting 
- Thrashing
- Reuses before it invents

Also, I don't see any discussion of self-learning that cascades back through the system. This is a key differentiator and should be highlighted on the "How it works" page and the skills pages where it makes sense. 

Change the title, "The chat is disposable. The artifact isn't." to something like, "Portable Artifacts: You or Teammate Can Pickup any Step Seamlessly."
